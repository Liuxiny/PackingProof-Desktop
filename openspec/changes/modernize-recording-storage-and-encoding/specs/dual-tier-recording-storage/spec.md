## ADDED Requirements

### 需求:网络录像必须先在本地完成
当最终存储位置是 UNC 或映射网络盘时，系统必须将视频、音频、封装结果和证明文件先写入用户配置的本机固定磁盘缓冲目录，禁止将网络路径直接交给录像写入进程。

#### 场景:网络主机在录像中离线
- **当** 网络主机在录像开始前或录像过程中不可访问
- **那么** 录像仍在本地完成并被标记为等待归档

### 需求:网络归档必须可恢复且可校验
系统必须通过持久化队列复制本地完成文件，使用网络端临时文件、长度与 SHA-256 校验以及同目录发布，并在程序重启后恢复未完成任务。

#### 场景:复制中断后恢复
- **当** 网络复制中断且程序随后重启
- **那么** 系统保留本地完整文件并重新尝试归档，禁止把不完整文件发布为正式录像

#### 场景:目标文件冲突
- **当** 网络正式文件已存在但哈希与本地文件不同
- **那么** 系统禁止覆盖，标记冲突并向用户显示原因

### 需求:录像访问必须网络优先本地兜底
系统必须由统一路径解析器为历史播放、下载、剪辑和 Web 访问选择文件；已验证且可用的网络文件优先，否则使用本地副本。

#### 场景:网络离线查看历史
- **当** 已归档录像的网络路径离线且本地副本仍存在
- **那么** 系统使用本地副本且历史界面保持可响应

### 需求:清理必须遵守录像生命周期所有权
系统禁止删除正在录制、封装、签名、复制或状态不明确的文件，失败任务禁止删除其他任务已发布的有效目标。

#### 场景:成功任务发布后失败任务清理
- **当** 任务 A 已发布并校验目标，随后任务 B 进入失败清理
- **那么** 任务 B 必须保留任务 A 的有效目标文件
