## ADDED Requirements

### 需求:最大录像时长必须使用秒数数字控件
系统必须将最大录像时长默认关闭；开启后默认 60 秒，并允许用户通过数字输入设置 15 至 600 秒。

#### 场景:启用最大录像时长
- **当** 用户开启最大录像时长且尚未设置新值
- **那么** 界面显示 60 秒并在 60 秒达到时停止录像

#### 场景:输入越界值
- **当** 用户输入小于 15 秒或大于 600 秒
- **那么** 系统阻止保存并显示合法范围

### 需求:最大时长必须独立于静止停止
系统必须分别配置最大录像时长和无活动自动停止，禁止一个设置覆盖另一个。

#### 场景:静止停止早于最大时长
- **当** 无活动停止条件先于最大时长达到
- **那么** 系统按无活动原因停止并记录正确停止原因
