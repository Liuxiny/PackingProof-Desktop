## ADDED Requirements

### 需求:录像水印必须包含证据信息
启用水印时，系统必须显示带时区的本地时间、快递单号或回退订单号，以及每秒变化的可读字母数字证明码。

#### 场景:录制期间证明码变化
- **当** 录像连续进行超过一秒
- **那么** 画面证明码至少更新一次且同一秒内保持稳定

### 需求:最终录像必须生成签名证明
系统必须以流式 SHA-256 计算最终录像哈希，生成包含录像元数据的 `.proof.json` 并用受当前 Windows 用户保护的设备密钥签名，禁止将整段录像加载进内存。

#### 场景:录像被修改
- **当** 用户对已签名录像内容做任意字节修改后执行校验
- **那么** 系统报告完整性校验失败

### 需求:网络归档必须包含证明文件
系统必须把最终录像和对应证明文件作为同一归档生命周期处理。

#### 场景:视频上传成功但证明文件失败
- **当** 视频已复制而证明文件复制或校验失败
- **那么** 系统禁止标记整条录像为归档完成
