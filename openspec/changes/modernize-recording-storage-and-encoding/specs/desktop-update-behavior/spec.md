## REMOVED Requirements

### 需求:桌面端自动更新
**Reason**: 桌面程序不得在启动或运行期间自动检查、下载、暂存或安装更新。

**Migration**: 启动器保留为纯启动入口；用户通过手动完整包或手动更新包升级。移除自动更新设置、服务、提示、缓存和自动 AppPatch 发布链路。

#### 场景:启动桌面程序
- **当** 用户启动根目录启动器或主程序
- **那么** 系统禁止发起桌面版本更新网络请求，也不读取或安装待处理自动补丁

## ADDED Requirements

### 需求:手动更新能力必须保留
系统必须允许用户通过主动获取的完整包或手动更新包升级，且启动器不得修改自身。

#### 场景:用户使用手动更新包
- **当** 用户主动运行受支持的手动更新流程
- **那么** 系统可以完成更新而不依赖自动检查服务
