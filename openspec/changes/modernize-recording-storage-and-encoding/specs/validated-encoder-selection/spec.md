## ADDED Requirements

### 需求:编码器列表必须经过实际试编码
系统必须把编码格式和实现绑定为一个完整选择项，只显示 FFmpeg 枚举且短时实际试编码成功的 CPU、Intel QSV、NVIDIA NVENC 或 AMD AMF H.264/H.265/AV1 编码器。

#### 场景:FFmpeg列出但硬件不可用
- **当** 编码器出现在 FFmpeg 列表但短时试编码失败
- **那么** 系统禁止把该编码器显示为可选项

### 需求:新配置默认自动编码
新配置必须默认使用 `auto`，并在每次录像开始前从已验证编码器中选择；录像记录必须保存实际编码器而不是 `auto`。

#### 场景:自动模式选择硬件编码
- **当** 自动模式检测到稳定可用的硬件编码器
- **那么** 系统使用该编码器并把实际 ID 写入录像记录

### 需求:固定编码器禁止静默回退
用户固定选择的编码器不可用时，系统必须阻止开始录像并提示“所选编码器不可用，请重新检测或选择其他编码器”。

#### 场景:固定QSV后来失效
- **当** 用户固定选择 QSV 编码器但开录前验证失败
- **那么** 系统不启动 FFmpeg，也不改用 CPU 或其他 GPU

### 需求:低性能软件编码必须警示
CPU H.265 和 CPU AV1 选项必须分别追加“（性能差，慎选）”。

#### 场景:显示CPU软件编码
- **当** CPU H.265 或 CPU AV1 试编码可用
- **那么** 选项文本包含性能警示
