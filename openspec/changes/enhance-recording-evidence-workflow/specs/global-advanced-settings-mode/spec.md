## ADDED Requirements

### 需求:高级模式开关必须位于设置左侧固定区域
“高级模式”全局开关必须位于设置窗口左侧导航的固定操作区并从任意设置页面可见，禁止继续把它作为“高级设置”页面内部的普通设置项。

#### 场景:从任意设置页面切换高级模式
- **当** 用户位于设备、录制、存储、语音、网络、条码或其他设置页面
- **那么** 用户必须能够直接在左侧切换高级模式而无需先进入高级设置页面

### 需求:高级模式必须即时控制全局专业参数并持久化
开关必须继续保存到用户配置，并立即更新所有设置页面中专业参数的可见性。关闭时系统必须避免键盘焦点停留在已隐藏控件上。

#### 场景:关闭高级模式
- **当** 用户关闭高级模式且当前焦点位于即将隐藏的专业控件
- **那么** 系统必须隐藏所有受控专业参数并把焦点移动到当前页面可见控件

#### 场景:重新打开设置窗口
- **当** 用户保存设置并再次打开设置窗口
- **那么** 左侧开关和所有专业参数可见性必须恢复为上次保存的状态
