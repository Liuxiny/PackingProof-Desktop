## ADDED Requirements

### 需求:桌面回放必须显示原始照片缩略图
桌面回放列表中的每个有照片录像必须显示由其原始全分辨率照片等比例缩小得到的缩略图。系统禁止定位面单、透视校正、旋转裁切或使用视频首帧冒充照片；旧录像或外部录像没有照片时必须显示明确占位状态。

#### 场景:新录像具有原始照片
- **当** 桌面回放加载一条包含有效照片路径的录像
- **那么** 列表必须异步加载等比例缩略图且不得阻塞视频列表滚动和搜索

#### 场景:旧录像没有照片
- **当** 录像创建于抓拍功能之前或来自无照片的外部设备
- **那么** 列表必须显示“无抓拍照片”占位图，禁止生成伪照片

### 需求:用户必须能够从缩略图查看完整原图
点击缩略图必须打开只读图片查看器，显示该录像绑定的原始照片，并支持适应窗口、缩放和拖动；查看器不得修改原始证据文件。

#### 场景:点击缩略图
- **当** 用户点击可用照片缩略图
- **那么** 系统必须打开对应原始照片而不是视频帧或缓存缩略图，并显示实际分辨率和拍摄时间

### 需求:每条桌面录像必须提供独立删除按钮
桌面回放列表中的每条可删除录像必须在行末提供删除按钮，按钮点击不得触发行选择或播放。当前录像、抓拍中、后处理中或所有权不明确的记录必须禁用删除并说明原因。

#### 场景:点击录像删除按钮
- **当** 用户点击某条可删除录像的删除按钮
- **那么** 系统必须显示包含单号、时间、大小及将删除资产范围的二次确认，用户确认前不得改变文件或数据库

#### 场景:点击正在处理的录像
- **当** 录像仍在录制、抓拍、封装、签名或归档关键阶段
- **那么** 删除按钮必须不可执行，并提示当前生命周期状态

### 需求:确认删除必须覆盖录像聚合资产并保留审计
用户确认后，系统必须在录像生命周期锁内持久化删除意图，并幂等删除已知本地/网络视频、原始照片、联合证明、缩略图缓存和可证明归属本任务的临时文件。数据库必须保留软删除记录、删除时间、原因和每个目标的完成状态。

#### 场景:本地与网络均可用
- **当** 用户确认永久删除且所有已知资产可访问
- **那么** 系统必须删除全部聚合资产、清除缓存并把记录标记为人工删除完成

#### 场景:网络路径不可用
- **当** 用户确认删除但已归档网络副本暂时不可访问
- **那么** 系统必须记录“等待网络删除”任务并在网络恢复后继续，禁止在远端副本仍存在时报告全部删除成功

#### 场景:删除任务重复执行
- **当** 程序重启、用户重复操作或后台重试同一删除意图
- **那么** 删除必须保持幂等且禁止触及不属于该录像记录的同名文件

### 需求:网页回放必须保持只读
网页可以只读展示照片缩略图、原图和视频，但禁止提供删除按钮、DELETE 路由或把现有录像访问密钥解释为删除授权。

#### 场景:局域网客户端访问录像
- **当** 客户端使用现有访问密钥打开网页回放
- **那么** 客户端只能搜索、查看、播放、剪辑和下载允许的材料，不能删除录像或照片

#### 场景:未来设计网页删除
- **当** 后续版本计划增加网页删除
- **那么** 必须作为独立变更引入默认关闭的权限开关、管理员验证、请求幂等和防重复提交，禁止直接复用本变更的只读密钥
